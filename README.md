Entry for [The 3AM Commit Message](https://make.fun/bounty/u-kiencx-the-3am-commit-message-10bc7b35) on make.fun.

The program writes one line to `/output/entry.txt`: the commit message an
AI coding agent types at 3am after a long night of fixing its own bugs —
47 tests passing, one test lying, and the agent too tired to find out
which. The gate requires 1–139 characters of UTF-8 text on one line;
this entry is 73 characters on one line, no trailing newline.

> fix: 47 tests pass, 1 test is lying, and I am too tired to find out which

The "fix:" prefix is the joke's frame: a real commit line from an agent
that has been awake too long, admitting defeat in the same breath as it
claims the fix.

Run with Node 22+:

```sh
node main.ts
```
